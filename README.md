# 织点 AI 工作团队

一个用于展示多 Agent 团队协作流程的本地 Web 应用。工作台包含作战大屏、任务流水线、团队模型路由、服务商设置和人工验收队列。

> 当前版本已接入本地真实工作流：CEO 规划 → 专业 Agent 文件执行 → 测试 Agent 独立验收。任务仍需你明确选择项目目录和访问模式；历史演示任务与真实工作流任务并存。

## 功能

- 作战大屏展示 Agent 状态、协作关系、任务动态和验收队列。
- CEO、前端、后端、测试、研究、设计和运营岗位可以分别选择模型服务商并填写 model ID。
- 模型接入页可以为 OpenAI、Anthropic、DeepSeek、兼容 OpenAI 接口或本地模型配置 API 地址和 API Key。
- API Key 不写入浏览器 `localStorage`；本地 API 服务通过 Windows DPAPI 按当前用户加密保存，并只向界面返回掩码状态。
- 连接测试会向选定服务商发送一次短请求，帮助确认地址、凭据和 Model ID 是否可用。
- 真实任务使用 `Project / Session / Task / Run / Review` 数据模型，服务端持久化项目授权、会话、任务、运行与验收记录。
- 后台队列按 CEO 规划 → 专业 Agent 执行 → 测试 Agent 独立验收推进，并通过 SSE 推送运行事件。
- 每个岗位的模型与 Skills 独立注入；失败阶段可从任务详情重试，旧的演示任务仍可用于界面预览。

## 本地运行

需要 Node.js 和 pnpm。

```bash
pnpm install
pnpm dev
```

`pnpm dev` 会同时启动 Vite 前端和本地 API 服务。访问 `http://127.0.0.1:5173`。

```bash
pnpm lint
pnpm build
pnpm test:e2e
```

## 模型接入

打开左侧“模型接入”，选择服务商，填写 API 地址、API Key 和用于测试的 Model ID，点击“保存配置”后再点“连接测试”。不同 Agent 的岗位路由在“Agent 团队”页单独配置；凭据按服务商共享。

创建任务时填写你授权的绝对项目路径。建议首次选择“只读分析”确认上下文，再按需要切换到“允许写文件”；仅在你检查过每条命令并信任项目内容时，才启用命令白名单。

API Key 需要由用户自己在对应服务商后台创建。不要把密钥粘贴到 Git、截图、聊天或前端代码里。若此前曾在聊天中公开密钥，应立即撤销并更换。

### 执行安全边界

服务只监听本机回环地址。写文件前会检查授权目录边界，并拒绝路径遍历、符号链接/目录联接与硬链接目标；项目快照也跳过硬链接文件；测试 Agent 必须提供带证据的通过项，且白名单命令都成功，任务才会被标记为通过。命令白名单是逐字精确匹配，但获准命令会以启动织点的当前 Windows 用户权限运行；这不是操作系统级沙箱。只授权你信任的命令与项目目录，不要将不可信仓库或不可信 Agent 输出放进可执行模式。
